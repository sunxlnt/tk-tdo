# TK-TDO Knowledge Base 

**Principal Investigator :** Dr. Mangkhollen Singson
**Year :** 2023 -2025

## Project Overview

This project aims to develop an ontology knowledge base providing a structured representation of traditional knowledge related to **Thadou-Kuki Tribe's major festivals, rituals, dance form and sport activities**, their cultural significance, and associated elements.

## Technologies

* **Ontology Language:** OWL
* **Ontology Editor:** Protégé

## Funding Agency
